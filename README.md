# Flow for Mac

A native download manager with segmented downloads, pause/resume, queues, scheduling, bandwidth controls and signed automatic updates.

[Download the developer preview](https://github.com/Vijyone/flow-downloads/releases/tag/v3.1.0-preview.1)

macOS 13 or later. Apple Silicon and Intel.

**Developer preview:** Apple Developer ID signing and notarization are pending. macOS may block installation. Do not disable system security; wait for a signed production release if macOS blocks the preview.

The source is maintained separately. This repository contains public installers and the cryptographically signed Sparkle update feed. Future updates download through Flow and installation waits for active downloads to finish. Check automatically and install automatically can be changed in Settings.
